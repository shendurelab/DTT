The scripts used for analyzing data from 107 monoclonal and 32 polyclonal gastruloids derived from ~50 bottlenecked mESCs, as described in the 'Linking the molecular state of founder mESCs to gastruloid fate bias' section.

Data: https://shendure-web.gs.washington.edu/content/members/cxqiu/public/nobackup/sam_tape/final_experiment/
